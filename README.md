# COM5507 Hong Kong Rental Livability Dashboard

Interactive data visualization of rental affordability, MTR-based commute, and neighborhood amenities for postgraduate students in Hong Kong.

## Live site

GitHub Pages will publish this repository at:

```text
https://GXF678.github.io/com5507-hk-rental-livability/
```

## Data sources

- 28Hse rental listings
- MTR Open Data
- OpenStreetMap POI, © OpenStreetMap contributors

## Notes

- Commute time is an MTR station-to-station proxy.
- Stations with low POI samples are excluded from dining rankings.
- This repository is for the COM5507 group project demonstration.
